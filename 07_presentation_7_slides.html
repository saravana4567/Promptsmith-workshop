Prompt Like an Engineer

Hands-on prompt engineering for 1st/2nd-year CSE students

By M. Saravanan

Why prompts matter

  • Vague prompt = random answer
  • Clear prompt = usable, checkable answer
  • Today: write, test, verify, save

Anatomy of a prompt

  • Role - Task - Context/Input
  • Format - Examples - Constraints
  • Verify (your job)

Before / After

  • Before: "fix my code"
  • After: "Python tutor: find the bug, explain in one sentence, show fix + 2 tests"
  • Score both with the checklist

Patterns

  • Few-shot: show examples
  • Chain-of-thought: step by step
  • ReAct: reason, look up, observe

Verify everything

  • Run the code
  • Check docs, dates, versions
  • Hunt for fake citations and functions

Ethics + Next steps

  • No private data in prompts
  • Credit sources, disclose AI help
  • Save good prompts in your library
