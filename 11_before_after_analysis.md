# Before/After Analysis

## Scoring method
Score each prompt with the 10-point Prompt-Quality Checklist. For each pair, run both prompts in the same tool and rate output on a 1-5 scale: relevance, correctness, usability.

## What typically changes (hypotheses to test, not results)
1. Adding a **format** removes the most rework.
2. Adding **context** (language/version/level) reduces wrong-level answers.
3. **Examples** improve style match more than extra instructions.
4. **Step-by-step** helps math/logic but still needs a verification step.
5. Longer is not always better: remove prompt text that doesn't change the output.
