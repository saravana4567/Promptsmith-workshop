# Quiz (12 Questions) - Prompt Engineering Basics
Name: ________  Time: 15 min

1. Which element tells the AI the perspective or expertise to adopt? A) Format B) Role C) Constraint D) Example
2. "Answer in a table with 3 columns" is which element? A) Role B) Context C) Format D) Verification
3. Giving 3 labeled examples before the real input is called: A) Zero-shot B) Few-shot C) ReAct D) Fine-tuning
4. Chain-of-thought prompting mainly helps with: A) Image resizing B) Multi-step reasoning C) File storage D) Grammar only
5. ReAct combines: A) Reading and acting on files B) Reasoning and acting with tools/lookups C) Rewriting and archiving D) Random sampling
6. Which prompt is better? A) `fix code` B) `Python 3.11: find the bug in this function, explain in one sentence, show fixed code`
7. Which should NOT be pasted into a public AI tool? A) A generic loop question B) Your college login password C) A public docs snippet D) A made-up sample dataset
8. The AI gives a citation you cannot find. Best action? A) Trust it B) Treat as possibly fabricated and verify C) Cite it anyway D) Ignore all sources
9. True/False: If code looks correct, you don't need to run it.
10. True/False: Official guides and primary papers are better sources than random blog posts for prompt techniques.
11. Short answer: Name two checks you do after receiving AI-generated code.
12. Short answer: Rewrite `explain recursion` using Role + Format.

---
# Answer Key
1. B  2. C  3. B  4. B  5. B  6. B  
7. B  8. B  
9. False - always run/test; code can look right and fail.  
10. True - though check dates, since model guidance changes.  
11. Any two: run it; write test cases (edge cases); read for security issues; check library/function exists in official docs; compare with a second source.  
12. Sample: "You are a friendly CS tutor. Explain recursion to a first-year student in 3 steps with one real-life analogy and a 5-line Python example."

Scoring: Q1-10 = 1 mark each, Q11-12 = 2 marks each (total 14). Mapping: 12-14 excellent, 9-11 good, <9 revisit checklist.
