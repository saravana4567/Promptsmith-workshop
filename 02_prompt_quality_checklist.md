# Prompt-Quality Checklist
Score 1 point per YES. 8-10 = strong, 5-7 = revise, <5 = rewrite.

| # | Check | Yes/No |
|---|---|---|
| 1 | **Role**: Did I say who the AI should act as (or the audience level)? | |
| 2 | **Task**: Is there one clear action verb (explain, fix, compare, summarize)? | |
| 3 | **Context**: Did I give needed background (language, version, course, goal)? | |
| 4 | **Input**: Is the exact text/code/data included (no private data)? | |
| 5 | **Format**: Did I specify structure and length (table, bullets, JSON, 100 words)? | |
| 6 | **Examples**: Did I add 1-3 examples when style/format matters? | |
| 7 | **Constraints**: Did I say what to avoid or limits (no libraries, simple words)? | |
| 8 | **Reasoning**: For hard tasks, did I ask for steps or a check of its work? | |
| 9 | **Safety/privacy**: Is the prompt free of passwords, IDs, personal data? | |
| 10 | **Verification plan**: Do I know how I will check the answer (run, search, compare)? | |

## After the answer
- [ ] I ran/tested any code
- [ ] I checked facts and dates against a reliable source
- [ ] I looked for made-up citations or APIs
- [ ] I rewrote the prompt if the output missed the goal
- [ ] I credited sources and disclosed AI help
